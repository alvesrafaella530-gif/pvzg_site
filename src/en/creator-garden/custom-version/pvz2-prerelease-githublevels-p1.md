**PvZ2_Prerelease_GithubLevels_P1** is a Gardendless mod that brings PvZ2 prerelease content into the game.

## Info

- Game version: **0.17.0**
- gp-next version: **1.6.2**

## Features

- Added Headbutter Lettuce
- Added Cattail
- Added Coffee Bean

## Note

- Load the mod with `gp-next` 1.6.2 on game version 0.17.0. Other versions may not work correctly.
- Make sure "Dynamic Plant Registry" is enabled in the F9 menu so the new plants show up.
